RIVALS: ARENA 3D
================
An original, fan-made first-person browser shooter in its own website folder. It uses simple shapes, not official Roblox RIVALS assets.

OPEN
- Open index.html in a modern desktop browser with an internet connection.
- Click DEPLOY. The mouse locks to the game; press Escape to pause.
- The 3D scene uses Three.js from cdnjs, so the first page load needs internet.

CONTROLS
- W A S D: move
- Mouse: aim
- Hold left mouse button: fire
- 1, 2, 3, 4: rifle, shotgun, sniper, pistol
- R: reload
- Shift: sprint
- Escape: pause / release mouse

WEAPONS
- AR-9 Rifle: balanced automatic weapon
- Breach Shotgun: close-range spread
- Longshot Sniper: slow, high-damage precision shots
- Sidearm Pistol: fast backup weapon

Bots deal 5 damage per shot and fire slowly, so health lasts longer than in the previous version. Clear a wave to advance; health restores a little between waves.

This fan-made browser game is separate from the RIVALS Fan Hub folder and is not affiliated with Roblox or Nosniy Games.
